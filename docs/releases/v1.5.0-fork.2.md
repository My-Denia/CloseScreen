# CloseScreen v1.5.0-fork.2

## Status

- Community-maintained CloseScreen release.
- Not an official OpenScreen successor.
- Windows and Linux release target.
- macOS is not a current release target.
- Builds are unsigned.

## Highlights

- Release-readiness documentation and contribution policy alignment.
- Export path IPC hardening: writes are restricted to one-time OS save-dialog-approved `.mp4` / `.gif` paths.
- Packaged OpenScreen/MIT attribution resources under `resources/licenses/`.
- Support/security/privacy/regression documentation.
- GitHub Releases link/check update policy alignment.
- Manual recordings retention cleanup.
- Repository identity and release readiness metadata alignment.

## Security and privacy notes

- Recording and export content remains local by default.
- Update checks use GitHub Releases link/check behavior.
- No auto-updater provider/token is introduced by this release.
- No telemetry is introduced by this release.
- Export writes require one-time save-dialog path approval.
- Retention cleanup uses manifest-gated, plan-first deletion with path containment checks.

## Platform support

- Windows: release target; unsigned build.
- Linux: release target; unsigned build.
- macOS: not currently provided / not currently verified as a release target.

## Known limitations

- Unsigned Windows builds may trigger SmartScreen or equivalent warnings.
- Linux packages may require manual trust / execution permissions depending on distribution and package type.
- macOS artifacts are not provided for this release.
- Some native capture behavior remains platform-dependent.
- Full installer smoke testing must be recorded in the release checklist.

## Manual verification checklist

- Windows installer launches.
- Linux AppImage launches.
- Linux package artifact, if generated, installs or extracts as expected.
- `resources/licenses/LICENSE` exists in packaged app.
- `resources/licenses/README.md` exists in packaged app.
- Screen recording smoke test.
- Export MP4 smoke test.
- Export GIF smoke test.
- Manual update check does not block startup.
- Manual recordings cleanup does not delete non-session user files.

## Checksums

- SHA256 checksums should be attached to the GitHub Release as `SHA256SUMS.txt`.
